# Security

drillpad is a local tool: it binds to `127.0.0.1` and runs the code you type in a subprocess. Do not expose it to a network
and do not run it on untrusted input you have not read.

Please report a suspected vulnerability privately through the repository's security advisory feature (Security tab, "Report
a vulnerability") instead of a public issue. Include what you found, how to reproduce it, and what you expect the impact to be.
