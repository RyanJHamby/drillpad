# Offers & Negotiation Basics

**Disclaimer: General guidance only. Not legal/financial advice. Consult HR/lawyer.**

## When Negotiation Starts

```
Offer received: email with comp package

You have: 48-72 hours to respond

DO:
  ├─ Thank them
  ├─ Say "I'm excited, reviewing details"
  └─ Ask deadline

DON'T:
  ├─ Accept immediately (leaves money on table)
  ├─ Negotiate over email (call instead)
  └─ Be rude or demanding
```

## What to Negotiate

```
Salary: base + stock + bonus

Base salary:
  ├─ Easiest to negotiate (fixed cost)
  ├─ Typical: 10-20% improvement possible
  ├─ Anchor high, willing to move
  └─ Example: "Given my background, I was expecting $200K"

Stock:
  ├─ More negotiable than salary (cost to company later)
  ├─ Example: "Can we increase equity by 0.1%?"
  └─ Track: vesting, strike price, dilution

Signing bonus:
  ├─ One-time, easier to add
  ├─ Example: "Can we add $50K signing bonus?"
  └─ Covers moving costs, etc.

Things harder to negotiate:
  ├─ Benefits (standard, not per-offer)
  ├─ Title (org structure)
  └─ Start date (usually fixed)
```

## Competing Offers

```
Use strategically:

Bad: "Company X offered me $300K, match or I leave"
  └─ Aggressive, burns bridge

Good: "I have strong interest in both roles. Company X is offering $270K. 
To join you, I'd need $260K base + 0.15% equity"
  └─ Respectful, gives them a number to beat

Don't invent offers:
  ├─ Recruiters can verify
  └─ Dishonesty kills deal

Timing:
  ├─ Get multiple offers before negotiating
  ├─ Then leverage (not before)
```

## Making a Decision

```
Comparison framework:

Base salary (40%)
  ├─ Take-home matters most
  ├─ $250K vs $300K = $1K/month difference
  └─ Significant, but not everything

Stock (30%)
  ├─ Startup: likely worthless (90% fail)
  ├─ Public company: more predictable
  └─ Ask: what's exit scenario? (IPO, acquisition, death)

Growth opportunity (20%)
  ├─ Role impact (will you level up?)
  ├─ Mentorship quality
  ├─ Brand (for resume)

Team & culture (10%)
  ├─ Will you like working there?
  ├─ Red flags: toxic, disorganized
```

## Common Mistakes

```
❌ Anchoring too low: "I was making $150K, so $180K is great"
  └─ You left money on table

❌ All-or-nothing: "Accept $300K or I'm out"
  └─ Burned bridge, no room to move

❌ Negotiating unilaterally: only discuss salary
  └─ Neglect stock, signing, or benefits

❌ Negotiating too long: 3+ rounds
  └─ They get frustrated, rescind
```

---

## Interview Checklist

- [ ] Ask for time to review (48-72 hours)
- [ ] Understand full comp (base, stock, bonus, benefits)
- [ ] Anchor high but reasonable
- [ ] Negotiate once, decisively
- [ ] Put offers in writing before accepting
- [ ] Consider total comp, not just salary

## When to Walk Away

```
❌ Disrespectful negotiation (lowball offers, pressure)
❌ Unclear stock (suspicious, can't trust)
❌ Red flags during process (poor org, scope creep)

Remember:
  ├─ You have leverage (they want you)
  ├─ Be respectful but firm
  └─ Wrong offer now = worse for 4 years
```
